## Post as published

Agentic retrieval beat dense retrieval by 8.7 nDCG points. It also took 160x longer per query.

NVIDIA's NeMo Retriever team wrapped the same embedding model in an LLM-driven ReAct loop. nDCG@10 rose 8.7 points on average, competitive on both ViDoRe v3 and BRIGHT. The bill: 107.4 seconds per query against 0.67, plus 764.1K input tokens.

My take: this does not replace your vector index. It is a second tier. Send the hard, multi-hop questions to the agent and keep the sub-second path for the rest. The routing decision is where the engineering work sits now.

Two more for anyone building agents:
Mistral Large 4 is in public preview: 1T parameters, 49B active, natively multimodal, trained on 3,800 Grace Blackwell GPUs. Weights land at the end of October.
Meta and Sierra published the Personal Agent Protocol: OAuth sessions where an agent starts as a guest and the user grants read-only or write access, via website, MCP or OpenAPI. v0.1 spec due this month.

Also worth your time:
Anthropic folded Project Glasswing into a three-tier Cyber Verification Program.
USC's OPPD trains a model so one generation beats 64-candidate power sampling on MATH500.

Would you pay 160x the latency for 8.7 points of retrieval quality? On which queries?

## Stories tracked

- NVIDIA NeMo Retriever paper (arXiv 2610.05750): agentic retrieval in a ReAct loop, +8.7 nDCG@10 with the same embedding model; 107.4 s vs 0.67 s per query; 764.1K input and 5.8K output tokens per query; competitive on ViDoRe v3 and BRIGHT.
- Mistral Large 4 public preview (6 Oct): 1T params, 49B active, natively multimodal, trained on 3,800 Grace Blackwell GPUs (Mistral's page; some coverage says 4,000), 82% on AA Cyber Index reproduce-and-patch test, 93% Cybench; weights end of October.
- Personal Agent Protocol (Sierra + Meta): OAuth sessions, guest then read-only or write, via website, MCP/OpenAPI or company agent; v0.1 spec due this month; payments future work; partners Genesys, Instinct, Rocket, Shopify, Stripe, Walmart.
- Anthropic Cyber Verification Program: Glasswing merged into three tiers (Defense, Red Team, Specialized).
- OPPD (USC, arXiv 2610.06804): one generation scores 2.4 points above 64-candidate power sampling on MATH500.
